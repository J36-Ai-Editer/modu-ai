# 1. ChatGPT Plus로 시작하기

이 저장소의 `index.html`, `app.css`, `app.js`를 ChatGPT에 첨부하고 다음을 요청합니다.

> 첨부한 생활습관 기록 웹 예제를 설명해줘. API 키나 유료 외부 서비스 없이 브라우저에서 실행하도록 유지해줘. 어떤 파일부터 열고 활동 체크와 대시보드 변화를 어떻게 확인할지 초보자에게 단계별로 알려줘. 실제 개인정보나 의료적 예측은 추가하지 마.

기대 결과: 날짜 선택, 활동 3개 체크, 진행률·공동 목표·새싹 보상 확인. ChatGPT의 인터페이스나 이용 한도는 달라질 수 있으며 Plus만으로 실제 의료 예측 서비스 운영이 완성되는 것은 아닙니다.
