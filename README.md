# 모두의 AI · Modu AI

생활습관 기록, 진행률 대시보드, 함께하는 목표, 게임형 보상을 작은 웹 앱으로 재현하는 학습용 저장소입니다.

## 가장 쉬운 시작

1. GitHub의 **Code → Download ZIP**으로 받습니다.
2. 압축을 풀고 `index.html`을 브라우저에서 엽니다.
3. 활동을 체크하고 대시보드·공동 목표·숲 보상이 바뀌는 것을 확인합니다.
4. ChatGPT Plus에 `prompts/01-start.md`와 필요한 코드 파일을 첨부해 원하는 수정을 요청합니다.

브라우저 예제에는 API 키·유료 API·서버가 필요하지 않습니다. ChatGPT Plus는 코드를 설명하고 수정하는 도움을 받는 선택 사항입니다. 파일 실행에서 저장이 제한되면 Python 설치 후 이 폴더에서 `python -m http.server 8765`를 실행하고 `http://localhost:8765`로 접속합니다.

## 포함 기능

- 날짜별 활동 기록·수정, 일일·최근 7일 진행률
- 이름이나 연락처 없이 코드로 구분하는 로컬 공동 목표 시뮬레이션
- 실천 기록에 연결된 숲 성장 보상
- JSON 내보내기·가져오기(입력 형식 검증), 초기화
- 외부 라이브러리 없이 동작하는 HTML/CSS/JavaScript
- Python 표준 라이브러리만으로 실행하는 합성 데이터 분류 학습 예제

**모든 기본 기록은 합성 시연 데이터입니다.** 공동 목표는 같은 브라우저의 예제이며 실제 다중 사용자 동기화는 아닙니다. 임상 당뇨 예측 모델·운영 백엔드·원본 게임 자산을 복제한 저장소가 아닙니다. 학습용 분류 예제의 특성과 점수에는 의학적 의미가 없습니다.

## 모델 학습 흐름 재현

```sh
python examples/train_synthetic.py
python -m unittest discover -s tests -p "test_*.py"
```

첫 명령은 고정 난수로 합성 데이터 생성 → 학습/평가 분리 → 로지스틱 분류 학습 → 평가 → 모델 JSON 저장 흐름을 보여줍니다. 실제 건강 데이터나 개인의 건강정보를 넣지 마세요. 실제 예측 모델의 적용·배포에는 원본 데이터 이용 조건, 검증, 전문 검토와 별도 운영 환경이 필요합니다.
